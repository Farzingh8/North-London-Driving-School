# Source artwork, deliberately outside `public/`

Anything in `public/` is copied into `out/` and deployed. These three files are
the originals the served assets were derived from, and nothing on the site links
to them, so keeping them here means the masters survive without shipping ~64 KB
of files no visitor ever requests.

| File | What it is |
|---|---|
| `brand/nlds-logo-alt.png` | 1080x360 master of the header logo. `public/brand/nlds-logo.webp` (384x128, 11 KB) is derived from it. Regenerate that if the logo changes. |
| `brand/nlds-favicon-150.png`, `-300.png` | The previous site's favicon at two sizes. The live favicon is generated by Next from `app/icon.png` and `app/apple-icon.png`, which are separate files. |
